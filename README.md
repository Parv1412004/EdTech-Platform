# EdTech-Platform

#STEP to RUN:  
--To run project first download zip file from github and then extract it.  
--Open the project file in VS Code (or any other code editor) and type the command "npm install" in the terminal to download dependencies.  
--type the command "cd server" and then "npm install" in the terminal to download server dependencies.  
--now open the ".env" file and add the required MONGODB, Cloud api key and secret_key etc.  
--now run command "npm run start" both in main terminal and server terminal.  
--Now run "node app.js" on the terminal, and our server is started.
